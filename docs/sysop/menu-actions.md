# SysOp menu actions: News, Bulletins, Demos and Goodbye

The operator-owned `config/sysop-menus.json` defines menus without editing application source. The menu engine validates IDs and restricts page destinations to a built-in allowlist.

## Three supported actions

```json
{
  "id": "example",
  "title": "Example Menu",
  "description": "A small demonstration",
  "items": [
    { "id": "welcome", "title": "Welcome Text", "action": "displayText", "textFile": "welcome" },
    { "id": "news", "title": "News Menu", "action": "openMenu", "menu": "news" },
    { "id": "dashboard", "title": "Dashboard", "action": "openPage", "page": "/dashboard" }
  ]
}
```

- **displayText**: reads a validated local `.asc` basename from the configured Mystic theme text directory, with a size cap, and displays it with the existing Mystic text renderer. The file must exist.
- **openMenu**: links to another configured menu by ID; unknown menus are rejected during validation.
- **openPage**: links only to an explicitly approved internal MysticWeb route. Arbitrary URLs, scripts, and external links are rejected.

The original News configuration entries using `textFile` without `action` remain supported for backward compatibility.

## Current screens

- **News**: four sources configured in JSON; their existing `/news` pages read the same catalog.
- **System Bulletins**: `/features/bulletins` uses the **existing native bulletin menu parser**, links to `/bulletins/[id]`, and preserves the existing individual bulletin renderer. It does not require manual JSON duplication.
- **Demos**: `/features/demos` reads the `demos` menu. Its example `demos.asc` is optional; missing files show an unavailable message. The example links to News and Dashboard. No program execution.
- **Goodbye**: `/features/goodbye` displays the configured `goodbye.asc` file when available and provides a Dashboard link. It **does not** end an authenticated session or disconnect a terminal caller.

## Customization and limits

Edit `config/sysop-menus.json` on the server and deploy/restart as appropriate for your hosting. Back up the file before changes. Keep the Mystic data directory operator-controlled and read-only for the web app. Text files are not uploaded or generated by this menu engine. Adding a new menu to the catalog creates its `/menus/<id>` route, but adding a top-level dashboard navigation item still requires navigation configuration. No untrusted JavaScript is evaluated.
